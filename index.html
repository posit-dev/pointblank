Package Info

Pointblank checks your tables for the problems that matter (missing values, out-of-range numbers, malformed text, duplicate rows) and reports what it finds in tables that analysts, engineers, and stakeholders can all read.

A validation, one part at a time

A validation is a table, a plan of checks, and a report. Step through this one to see what each part adds, with the new lines of code highlighted.

Plan

Say what good data looks like, one check per step. There are checks for values, text patterns, sets, missing values, duplicates, row counts, schemas, and more. Before the checks are run, the report shows the plan.

(
    pb.Validate(
        data=small_table,
        tbl_name="small_table",
        label="Checks on the sales data",
    )
    .col_vals_gt(columns="d", value=1000)
    .col_vals_not_null(columns="c")
    .col_vals_regex(columns="b", pattern=r"^\d-[a-z]{3}-\d{3}$")
    .col_vals_in_set(columns="f", set=["low", "mid", "high"])
    .rows_distinct()
)

Thresholds

Decide how much failure is too much. Thresholds set the share of failing rows that counts as a warning, an error, or a critical problem, and actions can run when one is reached.

(
    pb.Validate(
        data=small_table,
        tbl_name="small_table",
        label="Checks on the sales data",
        thresholds=pb.Thresholds(warning=0.05, error=0.10, critical=0.15),
    )
    .col_vals_gt(columns="d", value=1000)
    .col_vals_not_null(columns="c")
    .col_vals_regex(columns="b", pattern=r"^\d-[a-z]{3}-\d{3}$")
    .col_vals_in_set(columns="f", set=["low", "mid", "high"])
    .rows_distinct()
)

Report

Run the checks with interrogate(). The report shows every step: how many rows passed and failed, which thresholds were reached, and a CSV of the failing rows. With brief=True, each step also says in plain words what it checks.

(
    pb.Validate(
        data=small_table,
        tbl_name="small_table",
        label="Checks on the sales data",
        brief=True,
        thresholds=pb.Thresholds(warning=0.05, error=0.10, critical=0.15),
    )
    .col_vals_gt(columns="d", value=1000)
    .col_vals_not_null(columns="c")
    .col_vals_regex(columns="b", pattern=r"^\d-[a-z]{3}-\d{3}$")
    .col_vals_in_set(columns="f", set=["low", "mid", "high"])
    .rows_distinct()
    .interrogate()
)

Runs where your data lives

Pointblank works through Narwhals and Ibis, so the same plan runs unchanged on DataFrames and in databases, and the checks happen where the data is.
