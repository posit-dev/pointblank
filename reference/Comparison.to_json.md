# Comparison.to_json()

Get the comparison results as a JSON string.

Usage

[Source](https://github.com/posit-dev/pointblank/blob/main/pointblank/_compare.py#L1469-L1475)

``` python
Comparison.to_json(
    samples=True,
    limit=10,
    indent=2,
)
```

The structure is the same as that of [`to_dict()`](../reference/Comparison.to_dict.md#pointblank.Comparison.to_dict).
